# Investigation Template

## Question

State one narrow hypothesis/question.

## Triggering evidence

Reference exact weekly/commissioning/runtime evidence.

## Expected pre-state

Document source/model behavior before changes.

## Diagnostic

Specify one targeted diagnostic/probe.

## Result

Record raw evidence before interpretation.

## Classification

Choose one or more:
- EXPECTED_STATISTICAL_FLUCTUATION
- MODEL_INPUT_DEFECT
- MODEL_STRUCTURE_GAP
- UNCERTAINTY_MISCALIBRATION
- DATA_SOURCE_DEFECT
- BEHAVIOR_MODEL_GAP
- INSUFFICIENT_EVIDENCE
- CALIBRATION_CANDIDATE

## Decision

Patch, defer, collect more evidence, or close.

## Validation

Record actual tests/commissioning performed. Never record planned tests as passed.
