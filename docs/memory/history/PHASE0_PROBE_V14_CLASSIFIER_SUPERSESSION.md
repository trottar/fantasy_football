## Historical record

Probe v1.4 successfully measured local lineage artifacts and compared v0.36 against the exact public v0.35-fixed1 baseline.

Its high-level classifier was later found representation-incomplete because `fixed1` name detection did not distinguish `v0.35-fixed1` baseline names from a hypothetical `v0.36-fixed1` release.

The raw measurements are not invalidated. Only the classifier interpretation is superseded.

This record is historical evidence and must not override the current I-001 investigation state.
