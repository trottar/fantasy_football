# Evidence Index

Evidence stored here is curated and sanitized for durable repository use.

Raw authenticated ESPN/NFL data remains local unless deliberately transformed into a public-safe artifact.

Planned categories:
- `weekly/` — weekly Data/MC recap and closure
- `commissioning/` — release commissioning records
- `calibration/` — evidence supporting or rejecting empirical calibration

Raw observations must remain immutable. Derived/calibrated products are separate artifacts.
